Native, thoughtful, small

A good Mac citizen.

Nullwave is a true native menu-bar app. It launches at login when you ask, uses the system accent color, follows light and dark appearance, and generates audio locally.

  • ✓
    Headset call-mode detectionOptionally pauses when the same device handles input and output, then resumes afterward.
  • ✓
    No microphone recordingIt watches the selected audio route—not your audio, calls, or applications.
  • ✓
    Independent volumeNullwave never changes your Mac’s system volume.
